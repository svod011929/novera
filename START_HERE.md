# GFORT — START HERE

Это готовая рабочая папка для Cursor AI. Исходный код GFORT V10.6 уже извлечён в корень проекта. Не нужно распаковывать installer или собирать проект заново перед первым анализом.

## Единственная стартовая команда владельца

После открытия этой папки в Cursor напиши агенту:

> Прочитай START_HERE.md, AGENTS.md, все правила в .cursor/rules и docs/MASTER_PLAN.md. Начинай автономную работу со Stage 0. Production не трогай.

## Что Cursor должен сделать сразу

1. Прочитать `AGENTS.md`, `.cursor/rules/gfort-safety.mdc`, `docs/MASTER_PLAN.md` и `TASK_BOARD.md`.
2. Запустить безопасные локальные проверки: `bash scripts/verify_workspace.sh`.
3. Сравнить текущий исходный код V10.6 с `_reference/V10_5_SOURCE`.
4. Создать `_cursor_output/00_BASELINE_AUDIT.md` с картой архитектуры, API, workers, таблиц, финансовых инвариантов, рисков и различий V10.5 → V10.6.
5. Создать `_cursor_output/01_IMPLEMENTATION_PLAN.md` с небольшими последовательными итерациями.
6. Продолжать разрешённые локальные задачи по порядку без постоянных общих вопросов владельцу. Все допущения записывать в отчёт.

## Когда Cursor обязан остановиться и спросить владельца

- предлагается изменить формулы доходности, длительность цикла, principal, реферальные проценты или финансовые статусы;
- требуется настоящая seed-фраза, приватный ключ, production bot token, SSH или рабочий `.env`;
- нужна необратимая миграция production-БД;
- планируется отправка реальной транзакции или сообщения реальным пользователям;
- требуется подключение к production-серверу или установка релиза;
- выявлен P0/P1 риск потери денег, данных или двойной выплаты.

## Структура комплекта

- корень проекта — извлечённый исходный код V10.6 Admin Controls;
- `_reference/V10_5_SOURCE` — контрольный исходный код Safe Deploy;
- `_reference/INSTALLERS` — вся найденная история установщиков;
- `docs/MASTER_PLAN.md` — основное техническое задание в формате, удобном Cursor;
- `docs/GFORT_Cursor_AI_Master_Development_Plan.docx` — версия для владельца;
- `_owner_inputs` — место для скриншотов, логотипа, приоритетов и описаний ошибок;
- `_cursor_output` — место для отчётов, решений, тестов и release checklist;
- `.cursor/rules` и `AGENTS.md` — постоянные инструкции агента.

## Главная цель

Максимально улучшить дизайн, интерфейс, стабильность и удобство пользовательского Mini App и административной панели, сохранив финансовое ядро, данные, Safe Deploy и возможность отката.
