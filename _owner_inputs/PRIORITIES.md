# Приоритеты владельца

Текущий порядок по умолчанию:

1. Не допустить потери денег, данных и двойных выплат.
2. Исправить критические ошибки и авторизацию Telegram.
3. Максимально улучшить дизайн и мобильное удобство.
4. Полностью улучшить административную панель.
5. Добавить безопасные admin controls: рефбаланс, инвестиции и уровни партнёрки.
6. Улучшить уведомления, рассылки, тексты и кнопки.
7. Подготовить обратимый release candidate.

Cursor может уточнить этот файл по результатам Stage 0, но не меняет финансовые правила без решения владельца.
