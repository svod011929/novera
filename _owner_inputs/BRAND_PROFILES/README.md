# Как сделать своего бота (для чайника)

Никаких PowerShell, git и Docker знать не нужно.

## 7 шагов

### 1. Дважды кликните файл
В корне проекта найдите и откройте:

**`СОБРАТЬ_БОТА.bat`**

Откроется чёрное окно с вопросами.

### 2. Ответьте на вопросы
Окно спросит по очереди:

1. **Имя бота** — латиницей, например `AURORA` или `MyBot`
2. **Слоган** — можно просто нажать Enter
3. **Домен** — например `mybot.com` (без `https://`)
4. **IP сервера** — цифры из панели VPS, например `203.0.113.10`
5. **Ваш Telegram ID** — напишите боту [@userinfobot](https://t.me/userinfobot), скопируйте число

### 3. Дайте логотип
Выберите `1` (по умолчанию) — откроется папка  
`_owner_inputs\ПОЛОЖИТЕ_ЛОГОТИП_СЮДА`

Положите туда файл **`logo.jpg`** (или `logo.png`), вернитесь в чёрное окно и нажмите Enter.

### 4. Выберите цвет
Нажмите цифру и Enter:

| Клавиша | Цвет |
|--------|------|
| 1 | синий |
| 2 | зелёный |
| 3 | фиолетовый |
| 4 | золотой |
| 5 | красный |

Enter без цифры = синий.

### 5. Подтвердите
Проверьте сводку. Напишите `да` (или просто Enter) — начнётся сборка.

### 6. Заберите файл `.sh`
В конце окно покажет путь. Обычно файл лежит здесь:

`_cursor_output\releases\ИМЯ_BOOTSTRAP_INSTALLER_….sh`

Проводник часто откроется сам на этом файле.

### 7. Залейте на сервер и запустите
1. Откройте **WinSCP** (или FileZilla)
2. Слева найдите `.sh` файл, справа зайдите в `/root`
3. Перетащите файл мышкой
4. В **Putty** / терминале сервера выполните одну команду:

```bash
sudo bash /root/ИМЯ_ФАЙЛА.sh
```

5. Когда спросит **токен бота**:
   - Telegram → [@BotFather](https://t.me/BotFather)
   - `/newbot` (или `/token`)
   - скопируйте строку вида `123456:AA...`
   - вставьте в окно сервера и нажмите Enter  
     (буквы могут не отображаться — так и должно быть)

Готово. Токен на этом компьютере вводить не нужно — так безопаснее.

---

## Чего НЕ нужно делать

- Не править `profile.json` руками
- Не копировать папку `_template`
- Не учить PowerShell
- Не класть токен бота / кошелёк / пароли в файлы на Windows

## Для разработчика

- Тот же wizard: `scripts\make_branded_installer.ps1`
- Неинтерактивный smoke-тест:

```powershell
powershell -NoProfile -File scripts\make_branded_installer.ps1 `
  -NonInteractive -Yes `
  -ProductName SMOKEBOT -Tagline "Test" `
  -Domain smoke.example -Ipv4 203.0.113.50 `
  -OwnerId 1000000001 `
  -LogoPath _owner_inputs\BRAND_PROFILES\novera\assets\logo.jpg `
  -Theme blue
```

- Старый прямой путь без мастера:

```powershell
powershell -NoProfile -File scripts\build_bootstrap_installer.ps1 -BrandProfile <id>
```

Профили лежат в `_owner_inputs/BRAND_PROFILES/<id>/`.
