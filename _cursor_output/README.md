# Cursor output

Cursor сохраняет сюда:

- `00_BASELINE_AUDIT.md`;
- `01_IMPLEMENTATION_PLAN.md`;
- `DECISIONS.md`;
- `CHANGELOG.md`;
- `TEST_REPORT.md`;
- `SECURITY_REVIEW.md`;
- `RELEASE_CHECKLIST.md`;
- снимки интерфейса и другие доказательства проверки.

Исходный код не должен импортировать или обслуживать содержимое этой папки.
